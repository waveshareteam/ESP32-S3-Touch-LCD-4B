# Security Policy

[English](SECURITY.md) | [简体中文](SECURITY_ZH.md)

## Supported Content

Security updates apply to maintained source projects and documentation on the
default branch. Historical factory binaries may require a newer release rather
than an in-place update.

## Reporting a Vulnerability

Report security-sensitive issues privately through the
[Waveshare official contact page](https://www.waveshare.com/contact_us).

Include the affected board revision, firmware or example path, version or
commit, impact, reproduction details, and any proposed mitigation. Do not open
a public issue until the report has been reviewed and coordinated disclosure is
appropriate.
