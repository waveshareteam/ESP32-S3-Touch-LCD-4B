# Support

[English](SUPPORT.md) | [简体中文](SUPPORT_ZH.md)

## Repository Issues

Use GitHub Issues for reproducible problems with files maintained in this
repository. Include the board revision, example path, framework version,
reproduction steps, expected behavior, actual behavior, and complete build or
serial logs.

## Product and Order Support

For purchasing, warranty, shipping, or product-specific service, use the
[Waveshare contact page](https://www.waveshare.com/contact_us).

## Security Reports

Do not disclose security vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
