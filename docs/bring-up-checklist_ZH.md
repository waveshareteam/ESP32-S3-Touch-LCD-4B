# ESP32-S3-Touch-LCD-4B 上电检查清单

[English](bring-up-checklist.md) | [简体中文](bring-up-checklist_ZH.md)

每个已发布硬件修订都应完成本清单。向 README、BSP 或示例写入数值前，应在
`hardware/` 中记录证据。已勾选项目仅表示资料交叉核对，不表示电气或实物验证。

## 源资料

- [x] 收录已发布的两页原理图 PDF。
- [ ] 收录计划公开的 PCB 源文件或生产输出。
- [ ] 收录 BOM 并标识不装器件。
- [ ] 收录机械图和连接器位置。
- [ ] 记录产品名、PCB 丝印和硬件修订。
- [ ] 记录源文件工具和版本。

## 电源、启动与存储

- [ ] 验证所有电源轨、使能信号和上电依赖。
- [ ] 验证 USB 角色、ESD 保护和 USB 信号走线。
- [ ] 验证复位、启动和 ESP32-S3 启动配置脚。
- [ ] 从已发布资料记录安全输入电压和电流。
- [ ] 验证 Flash/PSRAM 类型、总线模式和容量。
- [ ] 验证 SD 卡或其他存储引脚及共享总线限制（如使用）。

## 显示、触摸与外设

- [x] 交叉核对 LCD 控制器、分辨率、RGB 总线和当前时序常量。
- [x] 交叉核对 LCD 复位、片选、命令/数据和背光控制。
- [x] 交叉核对 BSP/示例使用的 GT911 总线、中断和复位信号。
- [x] 确认由 TCA9554 转接的 LCD/触摸控制脚分配。
- [x] 交叉核对示例使用的 ES8311/ES7210 时钟、数据和功放使能。
- [x] 交叉核对示例使用的 QMI8658、PMU、RTC 和 GPIO0。
- [ ] 标识所有 GPIO 冲突与无法并行使用的外设。

## 最终核验

- [ ] 将原理图与 PCB 源文件或网表比较。
- [x] 将当前引脚定义与托管 BSP 头文件比较。
- [x] 将当前引脚定义与所有第一方示例及 Arduino 共享头文件比较。
- [ ] 在对应硬件修订的实物上测试。
- [ ] 验证完成后更新 `hardware/HARDWARE_REFERENCE_TEMPLATE.md` 并改为修订专属文件。
